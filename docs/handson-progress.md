## 確認待ち・実践メモ

- 参照コードは `sample/`、ユーザーの実装は別の作業場所とする。
- 実行の入口は作業用ディレクトリ直下の `main.py` に一本化する（2026-09-24）。`tiny_gpt/` の部品ファイルには `main()` や `if __name__` を置かず、各節の確認コードで `main.py` を書き換えて実行する。`check.py` と `python -m tiny_gpt.xxx` は使わない。
- 制作事情や過去の方針を本文へ混ぜず、ここで管理する。所要時間は実行条件と実測を踏まえて本文へ示す。
- Python・主要ライブラリは最新安定版へ揃える。採用版は計画資料に記録する。
- `core-message-writing` によるサブエージェントレビューと認知しづらい箇所のレビューを完了し、妥当な指摘を反映した。
- `cursor-agent --model gemini-3.7-flash-high` の日本語レビューを、ユーザーが承認した本文だけの一時ディレクトリで実行し、妥当な指摘を反映した。
- 入力例は「日本の／首都／は／東京／です／。」とし、shapeの `B` と区別する。語彙数は `vocab_size` と書き、Valueの `V` と区別する。
- 冒頭にBlock内部まで含むアーキテクチャ図を配置した。実験は節ごとに必須にせず、理解に役立つ比較と全体の動作確認へ絞った。
- 確認済みの実行条件と結果は、このページの「日本語版への更新」に記録する。
