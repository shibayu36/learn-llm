本文 1.5 / 内積 → softmax説明用の数値

矢印の向きと長さが、参照する割合を変える。

オレンジが参照する側のQuery、青が3つの参照先のKeyです。Queryの向きを変えると、それぞれのKeyとの内積が変わります。同じ向きでも、長さを変えると内積は変わります。

参照先q・k / √2exp割合

指数関数では数値を安定させるため、最大のscoreを引いています。softmaxの結果は変わりません。

まず「次へ」を2回押して、負のscoreも正の値になり、合計1の割合になる過程を見ましょう。次にQueryの長さを0へ下げると、3つとも同じ割合になります。

2次元の数値は説明のために置いたものです。座標軸に「名詞らしさ」などの意味は割り当てていません。内積が大きいことは、token同士の意味が近いことを直接保証しません。

本文 1.5 / 重み付き和説明用の数値

Valueを重みの分だけ縮めて、矢印をつなぐ。

上のデモで決めた割合を使い、3つのValueを集めます。1つずつweightを掛け、前の矢印の先から次の矢印を足してみましょう。すべてを足したベクトルがAttentionの出力です。

薄い矢印は元のValue、青はweightを掛けて足した分、オレンジは原点から見た合計です。Q・KとValueには別の数値を使っています。

output = weight₀ × v₀ + weight₁ × v₁ + weight₂ × v₂

上のQueryを変えると割合も変わり、足し算は最初へ戻ります。この出力はValueの重み付き和で、本文の出力変換やResidual Connectionを通す前の値です。

本文 1.5 / XからQ・K・Vを作る説明用の数値

同じ入力でも、Wを変えると集め方が変わる。

Q・K・Vは入力から計算するベクトルです。その変換に使うWq・Wk・Wvが、学習するパラメータです。このデモでは入力Xを固定し、Wだけを変えて違いを見ます。

X = [[2, 0], [0, 2], [1, 1]]
Q = XWq　K = XWk　V = XWv
shape: X・Q・K・Vは [3, 2]、各Wは [2, 2]

QとK：どの割合で集めるか

位置Keyscoreweight

V：何を集めるか

Wvだけを変えると左のweightは同じまま、右のValueと出力が変わります。

Wqを0にするとQも0になり、参照先の割合はすべて1/3になります。そのままWvを2倍にすると、割合を保ったまま出力だけが2倍になります。

入力ベクトル同士の内積だけでscoreを作ると、score(i, j)とscore(j, i)は同じです。別のWq・Wkを使うと、この対称性に縛られないscoreを作れます。ただしsoftmax後のweightは行ごとに正規化するため、元のscoreが対称でも対称とは限りません。

ここではバイアスとCausal Maskを省略しています。実際の学習ではWだけでなくEmbeddingも更新します。この操作はパラメータの役割を見るもので、学習結果の再現ではありません。

本文 1.6 / Causal Mask説明用の数値

「次に当てるtoken」が、入力の先に見えている。

入力を「日本の / 首都 / は」とします。位置1で次の「は」を予測するとき、位置2の「は」を参照できたら答えが見えてしまいます。生成時には使えない、この経路をMaskで閉じます。

Attention weight：行から列を見る

チェックすると未来のscoreを−∞にし、softmaxを計算し直します。未来の重みが0になり、見える位置だけで合計1になります。Maskは現在の位置も参照できます。

対応するPythonの計算を見る
scores = scores.masked_fill(future, float("-inf"))
weights = torch.softmax(scores, dim=-1)
本文 1.12説明用の数値

候補の順位と、選ばれる確率は別。

「日本の首都は」の次の候補を「東京」「大阪」「京都」とします。説明用のlogitsを [2, 1, 0] に固定します。temperatureを動かしても、元のlogitsは変わりません。

確率 = softmax(logits / temperature)

同じ分布から1token選ぶ

temperatureを0.2から2.5へ動かしてください。確率の差は変わりますが、一番高い候補は変わりません。greedyとsamplingで、それぞれ何度か選んでみましょう。
このデモの候補は 東京大阪京都 の3つだけです。実際のGPTは語彙全体のlogitsを返します。temperatureはモデルの重みを更新しません。
