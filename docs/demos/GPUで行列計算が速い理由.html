GPUはなぜ行列計算が速いの？

計算を、
みんなで分ける。

行列のかけ算は、小さな「かけて、足す」の集まり。
GPUはたくさんの計算係で、同時に進めるのが得意です。

01 / お仕事を小さく分ける

答えのマスは、別々に計算できる。

行列は「数字を並べた表」。左の横1列と右の縦1列で、答えを1マス作ります。

A：横の数字を使う
×
B：縦の数字を使う
=
答え：マスを押してみよう

隣の答えを待たなくていい。だから分担できる！

02 / 同じ作業をいっせいに

GPUには、計算係がたくさんいる。

CPUは複雑な判断や順番のある仕事が得意。
GPUは計算用の回路をたくさん並べ、同じ手順をまとめて進めます。

進めた回数：0

CPU

この模型では2係
↓
0 / 36マス計算前

GPU

この模型では12係
↓
0 / 36マス計算前

どちらも同じ36マスを埋めます。1マス＝1つの答え。

係の数と速さは説明用です。1係が1回に1マスを完成させると仮定し、準備・データ移動の時間は省いています。実際のコア数や速度比ではありません。CPUも並列に計算できます。

03 / たくさん並べる ＋ ふたつの工夫

数字を使い回す。まとめて計算する。

① 近くに置いて使い回す

行列では同じ数字を何度も使います。まとめて運び、近くの速いメモリで共有すると、取りに行く回数を減らせます。

② 専用回路でひとかたまり

対応するGPUには、小さな行列をまとめて「かけて、足す」回路もあります。NVIDIAのTensor Coreなどです。

仕事が少ないと、準備のほうが大変。

GPUに仕事を頼む準備にも時間がかかります。別のGPUメモリへ数字を運ぶ場合は、その時間も必要です。小さい計算ではCPUのほうが速いこともあります。

模型で省いたこと・参考資料

ここでは行列のかけ算を扱っています。実際は複数の係がマスのまとまりを協力して計算します。1マスの中にも足し合わせる手順があります。「1マスに1コアがつきっきり」という対応ではありません。

CPUにも複数のコアや複数の数値を同時に扱う命令があります。GPUは大量の同じ計算をこなすことに、より多くの回路を使う設計です。メモリから数字を運ぶ速さも性能を左右します。

速さは行列の大きさ・形・数値の精度・GPUの種類・計算方法で変わります。Tensor Coreが使える条件も機種や数値形式によって異なります。
