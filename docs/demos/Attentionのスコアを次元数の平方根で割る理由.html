ATTENTION · SCOREのばらつき

なぜ √d_k で割ると、
scoreのばらつきが揃うのか。

正負の値は打ち消し合います。それでも、たくさん足した合計は、0からのズレが大きくなりやすい。1回の足し算と、多数の足し算を分けて見てみましょう。

変えるのは1本のベクトルの成分数です。比較する相手の数は固定し、同じ乱数列の先頭から使います。

01 · 1つの内積を見る

＋1なら上へ、−1なら下へ。合計を追う。

内積は q₁k₁ + q₂k₂ + … という足し算です。このデモではQ・Kの各成分をランダムな＋1か−1にします。すると、1項の積も＋1か−1になり、折れ線の一歩として描けます。

足した項 16 / 16 ここまでの合計 0

1本だけを見ると、成分を足して合計が0へ戻ることもあります。「項が増えるたびに、必ず合計が大きくなる」という話ではありません。

02 · 多数の内積を比べる

中心は0付近のまま。散らばる幅が広がる。

1本のQと512本のKで内積を計算します。点1つが1つの内積です。成分数を16 → 64 → 256と増やし、左の点群が横へ広がる様子を見てください。右は同じ値を √d_k で割ったものです。

横位置が値を表します。縦の位置は重なりを減らすために散らしています。左右の横軸の範囲は異なりますが、成分数を変えても各図の目盛りは固定です。「ばらつき」は標準偏差で、平均からどれくらい離れるかの大きさを表します。

成分数 d_k割る前のばらつき割る値 √d_k割った後

なぜ「平方根」になるのか、式でも確かめる

1項の積を a、別の項の積を b とします。それぞれ独立に＋1か−1なので、二乗すると必ず1です。一方、abは正負が同じ確率で現れ、平均は0になります。

(a + b)² = a² + b² + 2ab 平均を取ると 1 + 1 + 0 = 2

d_k項でも同じです。別の項どうしの積は平均で0になり、各項の二乗だけが残ります。

合計の二乗の平均 = d_k 合計の大きさの目安 = √d_k √d_k で割った合計の二乗の平均 = d_k / (√d_k)² = 1

ばらつきそのものが√d_k倍になるので、√d_kで割ると揃います。d_kで割ると、成分数が大きいほど逆に小さくなりすぎます。

03 · Attentionの割合につなげる

scoreの差が大きいと、softmaxが一か所に偏る。

512本のKのうち4本を選んで比較します。参照先A〜Dは同じまま、成分数だけを変えます。各棒は、この4つに対するsoftmax後の割合です。

成分数

割らずにsoftmax

√d_k で割ってからsoftmax

割ることでscoreの大小の順序は変わりませんが、差の大きさは変わります。個々の乱数では同点になったり、偏りが小さくなったりする場合もあります。

√d_kで割る目的は、成分数の増加だけでscoreの差が広がりすぎるのを抑えること。入力に応じて参照先を選ぶ余地を残します。

このデモは、Q・Kの各成分を独立な±1として作ったシミュレーションです。学習済みモデルの測定値ではありません。各成分が独立で平均0・分散1という仮定では、内積の標準偏差は√d_kになります。実際の学習では分布や相関も変わるため、√d_kは成分数によるスケールの変化を補正する目安です。
