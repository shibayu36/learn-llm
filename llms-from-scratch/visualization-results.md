# 内部表現の可視化結果（2026-09-26）

`visualization-plan.md` の観察結果を記録する。予測性能の記録は `evaluation-results.md`。

## 1. Token embeddingの地図

PCAで2次元にした図の上の近さは、文字どうしの近さを表さなかった。2軸の寄与率は合計7%弱で、64次元をほぼ均等に使っているためである。一方、元の64次元でのコサイン類似度の近傍には、長↔短・高↔低・東↔西のような反対語や、東・西・南・北のような方角のまとまりがはっきり出た。図から読めるのは、ひらがな・漢字・カタカナ・数字という文字種の分かれ方だけである。

### 対象と条件

- 対象run: `l1h1-s5000-lr1e-3`（1層1ヘッド、d_model 64、5,000step、学習率1e-3、weight decay 0.1）
- `tok_emb.weight`（4,052 × 64）をそのまま使い、位置埋め込みは加えない
- PCAの軸は訓練データでの出現頻度上位300文字で当てはめ、全4,052文字を投影した
- 近傍は元の64次元ベクトルのコサイン類似度で求め、候補は出現100回以上の1,632文字に限った（理由は後述）
- UMAPは同じ1,632文字で計算した（metric cosine、n_neighbors 5、min_dist 0、seed 42）。設定の決め方は `progress.md`
- 図は `runs/l1h1-s5000-lr1e-3/embedding_map.html`（自己完結HTML）。元データは同じディレクトリの `embedding_map.json`

```bash
uv run main.py visualize-embeddings --run-name l1h1-s5000-lr1e-3
```

### PCAの2軸は散らばりの7%しか表さない

| 当てはめた集合 | 第1軸 | 第2軸 | 第3〜10軸 |
|---|---:|---:|---|
| 頻度上位300文字 | 3.6% | 3.3% | 3.2%〜2.5% |
| 全4,052文字 | 2.0% | 2.0% | 1.9%〜1.8% |

64次元に均等に散らばれば1軸あたり1.6%で、それと大差ない。文字どうしの違いの93%は図に出ない方向にある。d_model 128のrunでも2.5%・2.1%、2,000stepのrunでも3.2%・3.2%で、幅や学習量を変えても同じだった。

「高」で確かめると、図で重なっている文字は元の空間では無関係で、元の空間で近い文字は図では散っている。

| 文字 | 2次元での距離 | 64次元でのコサイン類似度 |
|---|---:|---:|
| 態 | 0.02 | −0.02 |
| 制 | 0.02 | 0.05 |
| 心 | 0.02 | 0.13 |
| 低 | 0.12 | 0.42 |
| 山 | 1.53 | 0.38 |

出現100回以上の全文字の組で、2次元の距離とコサイン類似度の相関係数は −0.13 だった。

### 元の空間の近傍には反対語と方角のまとまりが出る

対象の3組はいずれも、相方が近傍1位（低だけは2位）だった。意味が反対でも、同じ文型（「〜が高い/低い」「〜が長い/短い」「東京/西日本」）で使う文字は近くに置かれる。

|---|---:|---:|---|
| 長 | 3,604 | 短 0.472 | 短(0.47) 着(0.41) 老(0.38) 均(0.35) 化(0.35) 済(0.34) 早(0.34) 恵(0.33) 勝(0.32) 森(0.32) |
| 短 | 738 | 長 0.472 | 長(0.47) 貢(0.38) 若(0.37) 濃(0.37) 定(0.35) 驚(0.35) 稿(0.35) 寄(0.34) 周(0.34) 宮(0.33) |
| 高 | 6,534 | 低 0.419 | 低(0.42) 濃(0.39) 山(0.38) 強(0.37) 歌(0.36) 柔(0.36) 浴(0.34) 産(0.31) −(0.31) 弱(0.30) |
| 低 | 1,344 | 高 0.419 | 潜(0.44) 高(0.42) 狭(0.40) 扱(0.36) 近(0.35) 甘(0.32) 践(0.32) 球(0.31) 鳴(0.30) 女(0.30) |

- 「〜い」で終わる形容詞の漢字（長・短・老・早・若・濃・強・柔・弱・狭・近・甘）が互いの近傍に出る。次の文字が「い」「く」「さ」になりやすいという次文字予測の都合で、同じ方向に寄ったと読める
- 東・西の近傍に北・南が入り、方角の4文字がまとまる。「東京」「関西」など後ろに続く文字が似るためと考えられる
- 「着」「均」「貢」「潜」など、意味的な関係が思い当たらない文字も上位に入る。類似度0.3〜0.4は無関係な2ベクトルの値（64次元では標準偏差約0.125）より明らかに高いが、上位10のすべてに理由を付けられるわけではない

### 出現100回未満の文字はほぼ初期値のままなので候補から外す

| 訓練データでの出現回数 | 文字数 | 平均ノルム |
|---|---:|---:|
| 0（`<\|unk\|>`） | 1 | 4.58 |
| 1〜10 | 1,458 | 4.84 |
| 11〜100 | 965 | 4.95 |
| 101〜1,000 | 982 | 5.24 |
| 1,001〜10,000 | 548 | 5.57 |
| 10,001以上 | 98 | 5.57 |

`nn.Embedding` の初期値は平均0・分散1の正規分布で、64次元ならノルムはおよそ8。weight decay 0.1・学習率1e-3で5,000step縮めると倍率は (1 − 1e-4)^5000 ≈ 0.61 で、ノルムは約4.85になる。出現1〜10回の文字の平均4.84はこれと一致し、稀な文字の埋め込みは初期値を縮めただけのランダムなベクトルである。近傍の候補に入れると偶然の一致が混ざるため外した。

逆に候補を頻度上位300に絞りすぎると、短・低・西が外れて長の近傍1位は「化(0.35)」になる。HTMLでは最小出現回数を動かしながら確認する。

### 図から読めるのは文字種の分かれ方だけ

出現100回以上の文字を文字種で色分けすると、ひらがなが左・漢字が中央・カタカナが右に並び、数字は下に離れる。

| 文字種 | 文字数 | 第1軸の平均 | 第2軸の平均 |
|---|---:|---:|---:|
| ひらがな | 74 | −1.07 | +0.28 |
| 漢字 | 1,361 | −0.26 | −0.03 |
| 英字 | 52 | +0.68 | +0.57 |
| カタカナ | 81 | +1.39 | −0.03 |
| 数字 | 10 | 0.00 | −1.97 |

カタカナの次はカタカナ、数字の次は数字が来やすい。次の文字の種類を当てるのに効く方向が、点群の中で最も散らばりの大きい方向になっている。漢字は1,361文字が中央にかたまり、この2軸では内部の構造は読めない。

意味の近さは元の空間の近傍として、表記の種類は2次元の配置として観察できた。埋め込みは両方の情報を持つが、64次元の中で使っている方向が違う。

### UMAPの図では文字種が縁に分かれ、東・西は重なる

HTMLの投影をUMAPに切り替えると、次のように見える。

- 数字10文字は図の左端に、ほかから完全に離れた小さなかたまりを作る。カタカナは左下の縁に沿っていくつかの小さなかたまりに分かれ、英字は下側にまとまる。漢字1,361文字は中央の大きなかたまりで、ひらがなと記号はその中に散る
- 東と西はほぼ同じ点に重なる。長・短・高は中央で寄り合い、低だけ右に離れる
- 「〜い」形容詞の漢字や方角のまとまりが、PCAでは見えなかった図の隣接として現れる

UMAPで隣にある2文字が元の空間でも近いとは限らず、seedを変えると特定の組の配置は変わる（`progress.md`）。図の隣接は近傍一覧の類似度で裏を取る。
