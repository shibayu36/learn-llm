# 内部表現の可視化結果（2026-09-26）

`visualization-plan.md` の観察結果を記録する。予測性能の記録は `evaluation-results.md`。

## 1. Token embeddingの地図

PCAで2次元にした図の上の近さは、文字どうしの近さを表さなかった。2軸の寄与率は合計7%弱で、64次元をほぼ均等に使っているためである。一方、元の64次元でのコサイン類似度の近傍には、長↔短・高↔低・東↔西のような反対語や、東・西・南・北のような方角のまとまりがはっきり出た。図から読めるのは、ひらがな・漢字・カタカナ・数字という文字種の分かれ方だけである。

### 対象と条件

- 対象run: `l1h1-s5000-lr1e-3`（1層1ヘッド、d_model 64、5,000step、学習率1e-3、weight decay 0.1）
- `tok_emb.weight`（4,052 × 64）をそのまま使い、位置埋め込みは加えない
- PCAの軸は訓練データでの出現頻度上位300文字で当てはめ、全4,052文字を投影した
- 近傍は元の64次元ベクトルのコサイン類似度で求め、候補は出現100回以上の1,632文字に限った（理由は後述）
- UMAPは同じ1,632文字で計算した（metric cosine、n_neighbors 5、min_dist 0、seed 42）。設定の決め方は `progress.md`
- 図は `runs/l1h1-s5000-lr1e-3/embedding_map.html`（自己完結HTML）。元データは同じディレクトリの `embedding_map.json`

```bash
uv run main.py visualize-embeddings --run-name l1h1-s5000-lr1e-3
```

### PCAの2軸は散らばりの7%しか表さない

| 当てはめた集合 | 第1軸 | 第2軸 | 第3〜10軸 |
|---|---:|---:|---|
| 頻度上位300文字 | 3.6% | 3.3% | 3.2%〜2.5% |
| 全4,052文字 | 2.0% | 2.0% | 1.9%〜1.8% |

64次元に均等に散らばれば1軸あたり1.6%で、それと大差ない。文字どうしの違いの93%は図に出ない方向にある。d_model 128のrunでも2.5%・2.1%、2,000stepのrunでも3.2%・3.2%で、幅や学習量を変えても同じだった。

「高」で確かめると、図で重なっている文字は元の空間では無関係で、元の空間で近い文字は図では散っている。

| 文字 | 2次元での距離 | 64次元でのコサイン類似度 |
|---|---:|---:|
| 態 | 0.02 | −0.02 |
| 制 | 0.02 | 0.05 |
| 心 | 0.02 | 0.13 |
| 低 | 0.12 | 0.42 |
| 山 | 1.53 | 0.38 |

出現100回以上の全文字の組で、2次元の距離とコサイン類似度の相関係数は −0.13 だった。

- 「〜い」で終わる形容詞の漢字（長・短・老・早・若・濃・強・柔・弱・狭・近・甘）が互いの近傍に出る。次の文字が「い」「く」「さ」になりやすいという次文字予測の都合で、同じ方向に寄ったと読める
- 東・西の近傍に北・南が入り、方角の4文字がまとまる。「東京」「関西」など後ろに続く文字が似るためと考えられる
- 「着」「均」「貢」「潜」など、意味的な関係が思い当たらない文字も上位に入る。類似度0.3〜0.4は無関係な2ベクトルの値（64次元では標準偏差約0.125）より明らかに高いが、上位10のすべてに理由を付けられるわけではない

### 出現100回未満の文字はほぼ初期値のままなので候補から外す

| 訓練データでの出現回数 | 文字数 | 平均ノルム |
|---|---:|---:|
| 0（`<\|unk\|>`） | 1 | 4.58 |
| 1〜10 | 1,458 | 4.84 |
| 11〜100 | 965 | 4.95 |
| 101〜1,000 | 982 | 5.24 |
| 1,001〜10,000 | 548 | 5.57 |
| 10,001以上 | 98 | 5.57 |

`nn.Embedding` の初期値は平均0・分散1の正規分布で、64次元ならノルムはおよそ8。weight decay 0.1・学習率1e-3で5,000step縮めると倍率は (1 − 1e-4)^5000 ≈ 0.61 で、ノルムは約4.85になる。出現1〜10回の文字の平均4.84はこれと一致し、稀な文字の埋め込みは初期値を縮めただけのランダムなベクトルである。近傍の候補に入れると偶然の一致が混ざるため外した。

逆に候補を頻度上位300に絞りすぎると、短・低・西が外れて長の近傍1位は「化(0.35)」になる。HTMLでは最小出現回数を動かしながら確認する。

### 図から読めるのは文字種の分かれ方だけ

出現100回以上の文字を文字種で色分けすると、ひらがなが左・漢字が中央・カタカナが右に並び、数字は下に離れる。

| 文字種 | 文字数 | 第1軸の平均 | 第2軸の平均 |
|---|---:|---:|---:|
| ひらがな | 74 | −1.07 | +0.28 |
| 漢字 | 1,361 | −0.26 | −0.03 |
| 英字 | 52 | +0.68 | +0.57 |
| カタカナ | 81 | +1.39 | −0.03 |
| 数字 | 10 | 0.00 | −1.97 |

カタカナの次はカタカナ、数字の次は数字が来やすい。次の文字の種類を当てるのに効く方向が、点群の中で最も散らばりの大きい方向になっている。漢字は1,361文字が中央にかたまり、この2軸では内部の構造は読めない。

意味の近さは元の空間の近傍として、表記の種類は2次元の配置として観察できた。埋め込みは両方の情報を持つが、64次元の中で使っている方向が違う。

### UMAPの図では文字種が縁に分かれ、東・西は重なる

HTMLの投影をUMAPに切り替えると、次のように見える。

- 数字10文字は図の左端に、ほかから完全に離れた小さなかたまりを作る。カタカナは左下の縁に沿っていくつかの小さなかたまりに分かれ、英字は下側にまとまる。漢字1,361文字は中央の大きなかたまりで、ひらがなと記号はその中に散る
- 東と西はほぼ同じ点に重なる。長・短・高は中央で寄り合い、低だけ右に離れる
- 「〜い」形容詞の漢字や方角のまとまりが、PCAでは見えなかった図の隣接として現れる

UMAPで隣にある2文字が元の空間でも近いとは限らず、seedを変えると特定の組の配置は変わる（`progress.md`）。図の隣接は近傍一覧の類似度で裏を取る。

## 2. Hidden stateの変化（次の文字の予測と近い文脈）

1層を通ったあとの「行」は、前にある文脈によって「行う・行った」の動詞の仲間にも「銀行・実行」の熟語の仲間にもなる。動詞寄りか熟語寄りかは、直前の文字（銀・実）と前文の両方で動く。一方「の」は、どの文脈でも「名詞のあとのの」として同じ扱いになり、文脈による差はほとんど出なかった。

### 対象と条件

- 対象run: `l1h1-s5000-lr1e-3`（1層1ヘッド、d_model 64）
- 入力は `data/hidden-state-sentences.json` の6文。前文8文字＋「銀行・旅行・実行・発行」の4文に、前文と単語を入れ替えた「処理が完了した。銀行の…」「お金を預けたい。実行の…」を足した
- 対象は位置9の「行」と位置10の「の」。Layer 0はブロックへの入力（token埋め込み＋位置埋め込み）、Layer 1はブロックの出力で、いずれも `final_norm` の前
- 次の文字の予測は、各層のベクトルを `final_norm` → `out_head` → softmaxに通した上位10（logit lens）
- 近い文脈は、validationの先頭39,936 token（256幅の窓156個）を同じモデルに通した各層のベクトルから、コサイン類似度の上位10
- 表は `runs/l1h1-s5000-lr1e-3/hidden_states.html`、元データは同じディレクトリの `hidden_states.json`

```bash
uv run main.py visualize-hidden-states --run-name l1h1-s5000-lr1e-3
```

### Layer 0では全文が同じ

Layer 0のベクトルは文字と位置だけで決まるので、6文とも予測も近傍も同一になる。「行」の予測上位は間(0.04)・動(0.01)・響・更で、埋め込みだけでは「行間・行動」のような熟語の続きを出す。近傍は別の位置にある「行」で、類似度は0.79〜0.80にとどまる（位置埋め込みの差）。文どうしのコサイン類似度は定義どおり1.000。

### 「行」はLayer 1で動詞の仲間と熟語の仲間に分かれる

Layer 1の予測上位5と、近傍上位10のうち「行う・行った・行われ・行く」のような動詞の使われ方だった個数。

| 文（対象まで） | 実際の次 | 予測上位5 | 近傍10中の動詞 |
|---|---|---|---:|
| お金を預けたい。銀行 | の | う(0.11) い(0.11) き(0.06) っ(0.06) 動(0.06) | 8 |
| 休暇を楽しもう。旅行 | の | う(0.28) っ(0.13) い(0.12) く(0.05) わ(0.03) | 8 |
| 処理が完了した。実行 | の | 為(0.06) の(0.05) 動(0.05) っ(0.04) が(0.03) | 2 |
| 書類を受領した。発行 | の | し(0.05) っ(0.05) う(0.05) い(0.05) く(0.04) | 3 |
| 処理が完了した。銀行 | の | 為(0.05) き(0.05) い(0.05) し(0.05) う(0.04) | 6 |
| お金を預けたい。実行 | の | 動(0.08) っ(0.06) う(0.05) い(0.05) 為(0.04) | 4 |

- 「銀行」「旅行」のあとの行は、予測が「う・い・っ・く」（行う・行い・行った・行く）に寄り、近傍も「美容整形を[行]う」「時間に[行]ったの」「によって[行]われて」のような動詞の行が8個を占める。「実行」「発行」のあとは、近傍が「␤銀[行]、」「非[行]など」「先[行]投資」「団体旅[行]の」のような熟語の行に入れ替わり、予測も「為（行為）・の・動」に変わる
- ただし予測の確率は最大でも0.28で、実際の次の文字「の」は最も高い文でも0.05。1層1ヘッドの段階では、文脈で候補の傾向は変わるが、次の文字を当てられるほど絞れてはいない
- 前文だけ入れ替えると（お金を預けたい→処理が完了した、銀行はそのまま）動詞の近傍は8個から6個に、直前の単語だけ入れ替えると（銀行→実行）8個から4個に減った。逆方向も同様で、実行の2個は前文の入れ替えで4個、単語の入れ替えで6個になった。直前の1文字の方が動かす量は大きいが、前文だけでも動く。前文と単語のどちらか一方で決まってはいない
- 元の空間のコサイン類似度でも同じことが読める。前文だけが同じ組は0.959と0.970、直前の単語だけが同じ組は0.931と0.966、どちらも違う組は0.895〜0.941。どちらも同じ文はないので、両方が効いた分だけ離れる

Layer 1の文どうしのコサイン類似度（位置9）。

| | お金/銀行 | 休暇/旅行 | 処理/実行 | 書類/発行 | 処理/銀行 | お金/実行 |
|---|---:|---:|---:|---:|---:|---:|
| お金/銀行 | 1.000 | 0.972 | 0.895 | 0.904 | 0.931 | 0.959 |
| 休暇/旅行 | | 1.000 | 0.903 | 0.921 | 0.939 | 0.948 |
| 処理/実行 | | | 1.000 | 0.971 | 0.970 | 0.966 |
| 書類/発行 | | | | 1.000 | 0.945 | 0.965 |
| 処理/銀行 | | | | | 1.000 | 0.941 |

予測上位には前文の末尾の文字が入る。「楽しもう」のあとは「う」が0.28で突出し、「預けたい」のあとは「い」が2位、「受領した」のあとは「し」が1位になる。1つしかないヘッドが前にある文字をそのまま写す動きをしている可能性があるが、この表だけでは確かめられない。Attentionの重みを見るときに確認する。

### 「の」は文脈によらず同じ扱いになる

位置10の「の」では、Layer 1の予測上位は6文とも「た・よ・方・中・人・場」が0.01〜0.02で並び、実質的に絞れていない。近傍は6文とも「アクセス[の]種類」「ゴールド[の]価格」「未知[の]バリエ」のような名詞に続く「の」で、類似度は0.977〜0.985。文どうしのコサイン類似度は最小でも0.971（お金/銀行と処理/実行）で、「行」の0.895より明らかに高い。

「の」は直前が名詞ならその先の候補が広すぎて、前文の違いを取り込んでも予測に使えない。1層のモデルは「の」を文脈で区別する方向にベクトルを動かしていない。入れ替えた文で見ると、直前の単語が同じ組（0.988・0.996）の方が前文が同じ組（0.981・0.986）より近く、「の」の表現は前文よりも直前の2文字で決まっている。

### 読み方の注意

- 予測の傾向と近傍の仲間分けは、文脈が表現を変えていることの観察であって、「銀行の行は動詞だとモデルが理解した」という意味ではない。実際「銀行の」の行は熟語であり、動詞寄りの予測は外れている
- 1層1ヘッドなので、Layer 0からLayer 1への1回の変化しか見ていない。層を積んだあとに、どの層でこの分かれ方が起きるか、層を進むと予測が絞られるかを同じコマンドで見る
