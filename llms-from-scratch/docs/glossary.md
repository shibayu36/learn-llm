# 用語集

学習中に見返すための短い用語集。用語は本『つくりながら学ぶ！LLM自作入門』の訳語に合わせ、別名を併記する。数値はこのリポジトリの基準条件（`plan.md`）のもの。

## 学習の進め方

| 用語 | 別名 | 意味 |
|---|---|---|
| step | 更新、イテレーション | 1バッチでパラメータを1回更新すること。ここでは2,000 stepで1回の学習とする |
| epoch（エポック） | 周 | 訓練データを端から端まで1回全部見ること。ここでは1,447バッチ = 1,447 stepで1 epoch。2,000 stepは約1.4 epoch |
| バッチ | batch、ミニバッチ | 1 stepでまとめて処理する系列の束。ここでは16系列 × 256文字 = 4,096文字 |
| 学習率 | learning rate、lr | 勾配の方向へパラメータを動かす量の倍率。ここでは3e-4 |
| 勾配 | gradient | 「lossを減らすには各パラメータをどちらへ動かせばよいか」を表す値。`loss.backward()` で全パラメータ分まとめて計算する |
| 誤差逆伝播 | backpropagation、backward | 出口のlossから各パラメータの勾配を逆向きにたどって求める計算 |
| optimizer | 最適化器、最適化アルゴリズム | 勾配を受け取ってパラメータを実際に更新する部品。`optimizer.step()` |
| AdamW | | optimizerの一種。パラメータごとに「最近の勾配の平均」と「ばらつき」を覚え、動かす量を個別に調整する。Adamに重み減衰を正しく組み込んだ改良版で、LLMの訓練で標準 |
| 重み減衰 | weight decay、`weight_decay` | 更新のたびに全パラメータを少しだけ0へ近づける仕組み。一部のパラメータだけ極端に大きくなって丸暗記するのを防ぐ。本は0.1 |
| ハイパーパラメータ | | 学習で更新されず、人が決める設定値。`d_model`、学習率、バッチサイズ、stepなど |
| seed | 乱数の種 | 乱数の出発点。同じseedなら初期値やシャッフル順が同じになり、結果を再現できる |
| 訓練モード / 評価モード | `model.train()` / `model.eval()` | 訓練時だけ働く部品（ドロップアウトなど）のON/OFF切り替え。生成や評価の前に `eval()` にする |
| 勾配の追跡 | `torch.no_grad()` | 勾配計算のためにPyTorchが取る記録。評価や生成では不要なので `no_grad()` の中で止め、時間とメモリを節約する |
| state_dict | | モデルの全パラメータを「名前 → テンソル」の辞書にしたもの。`torch.save` で保存し、`load_state_dict` で復元する |
| チェックポイント | checkpoint | 学習途中のモデル（と必要ならoptimizer）を保存したもの |

## モデルの部品

| 用語 | 別名 | 意味 |
|---|---|---|
| パラメータ | 重み（全体を指すとき） | 学習で更新される値の総称。ここでは1層1ヘッドで580,800個 |
| 重み行列 | weight | 特定の行列を指すときの呼び方。`W_query`、Embeddingの重みなど |
| 全結合層 | Linear層、線形層、`nn.Linear`、dense layer | 入力ベクトルに重み行列を掛けて（必要ならバイアスを足して）別の次元のベクトルにする部品。Q/K/V、フィードフォワード、出力ヘッドはすべてこれ |
| バイアス | bias | 全結合層で掛け算のあとに足す定数ベクトル。ここではQ/K/Vと出力ヘッドは `bias=False` |
| 埋め込み | Embedding、`nn.Embedding` | トークンID → ベクトルの表引き。トークン埋め込み（何の文字か）と位置埋め込み（何番目か）の2種類を足して入力にする |
| 層正規化 | LayerNorm、Layer Normalization | 1つの位置のD個の成分を平均0・分散1にそろえる部品。値の桁が膨らんで訓練が不安定になるのを防ぐ。`scale`・`shift` の2つのパラメータを持つ |
| ショートカット接続 | 残差接続、Residual Connection、skip connection | 層の出力で入力を置き換えず、入力に足す `x = x + f(x)`。勾配が入口まで減衰せず届く直通路になる |
| Pre-LayerNorm | Pre-LN | 各部品の前に層正規化を置く構成。GPT-2の形。後ろに置くのがPost-LayerNorm |
| フィードフォワードネットワーク | FFN、MLP、`FeedForward` | 全結合層 → GELU → 全結合層。中間で次元を4倍に広げてから戻す。位置ごとに独立で、他の位置は混ぜない |
| GELU | | 滑らかな活性化関数。負をほぼ0、正をほぼそのまま通す。これがないと2つの全結合層が1つの線形変換にまとまってしまう |
| 活性化関数 | activation | 全結合層の間に挟む非線形な関数。GELU、ReLUなど |
| Attention | Self-Attention、注意機構 | 各位置が他の位置をどれだけ参照するかを計算し、参照先の値を加重和で取り込む部品 |
| Causal Attention | マスク付きAttention、masked attention | 未来の位置を見られないようにマスクしたAttention。GPTはこれ |
| Multi-head Attention | MHA | Attentionを複数個（ヘッド）並列に計算して連結したもの。Stage 5 |
| Q・K・V | クエリ・キー・値 | Attentionの3つの射影。クエリは「何を探すか」、キーは「照合される側」、値は「取り出す内容」 |
| Attentionの重み | attention weight | softmax後の参照割合。行ごとに合計1 |
| Transformerブロック | Block、層 | 層正規化 → Attention → ショートカット接続 → 層正規化 → FFN → ショートカット接続の1まとまり。これを積んだ数が「層数」 |
| ドロップアウト | Dropout | 訓練中にランダムに一部の値を0にして、特定の経路への依存（過剰適合）を防ぐ部品。評価時は無効になる。ここでは使わない |
| 出力ヘッド | LM Head、`out_head` | 最後の全結合層。Dのベクトルを語彙数ぶんのロジットにする |
| `d_model` | 埋め込み次元、emb_dim、D | 1トークンを表すベクトルの次元数。ここでは64 |

## 損失と評価

| 用語 | 別名 | 意味 |
|---|---|---|
| ロジット | logits | 出力ヘッドが出す語彙数ぶんの生の値。softmaxで確率に変える前の値 |
| softmax | | 値の列を合計1の確率に変換する関数 |
| 損失 | loss、誤差 | 「どれだけ間違えたか」を1つの数にしたもの。小さいほどよい |
| 交差エントロピー誤差 | cross entropy loss | 正解の文字に割り当てた確率 p の -log(p) を全位置で平均した損失。学習前は ln(語彙数)=8.31 付近 |
| パープレキシティ | perplexity | exp(loss)。「次の文字の候補が実質何個に絞れているか」。学習前は語彙数（4,052）付近 |
| 訓練セット / 検証セット | train / validation | 学習に使うデータ / 学習に使わず評価だけに使うデータ。ここでは9,000文書 / 1,000文書 |
| train loss / validation loss | | 訓練セット / 検証セットで測った損失。2本を並べて過剰適合を見る |
| 過剰適合 | 過学習、overfitting | 訓練データを丸暗記して、見たことのないデータで悪くなる状態。train lossだけ下がりvalidation lossが下がらない |
| 汎化 | generalization | 見たことのないデータでも正しく動くこと |
| 評価 | evaluation、eval | 学習を止めて固定のバッチでlossを測ること。ここでは200 stepごとに8バッチ |
| 損失曲線 | loss curve | 横軸step、縦軸lossの図。下がり方と、train / validationの差を見る |

## 生成

| 用語 | 別名 | 意味 |
|---|---|---|
| 生成 | 推論、デコーディング | promptの続きを1トークンずつ選んで末尾に足すことを繰り返す処理 |
| prompt | 入力文 | 生成の起点として渡す文字列 |
| 貪欲なデコーディング | greedy decoding、argmax | 毎回いちばん確率が高いトークンを選ぶ。毎回同じ出力になる。ここでは `temperature=0` |
| サンプリング | sampling、`multinomial` | 確率に応じたくじ引きでトークンを選ぶ。毎回違う出力になる |
| temperature | 温度 | ロジットをこの値で割ってからsoftmaxする。小さいほど最大の1つに集中し、大きいほど平らになる。1でスケーリングなし |
| top-k | | 確率上位k個以外を候補から外してからサンプリングする。低確率の変な文字が混ざるのを防ぐ |
| context length | 文脈長、`context_length`、T の上限 | モデルが一度に見られる最大トークン数。ここでは256。それより古い入力は見えなくなる |

## データ

| 用語 | 別名 | 意味 |
|---|---|---|
| トークン | token | モデルが扱う最小単位。ここでは1文字 = 1トークン |
| トークナイザ | Tokenizer | 文字列 ↔ トークンID列の変換器 |
| 語彙 | vocab、`vocab_size` | トークナイザが知っているトークンの一覧。ここでは4,052 |
| EOS | `<\|endoftext\|>`、終端トークン | 文書と文書の区切りを表す特別なトークン |
| UNK | `<\|unk\|>`、未知トークン | 語彙にない文字の置き換え |
| 系列 | シーケンス、sequence | 1つの入力に含まれるトークンの並び |
| 窓 | ウィンドウ、チャンク | 長いトークン列から切り出した固定長（256）の系列。入力と、1つ後ろにずらした正解の組になる |
| スライディングウィンドウ | | 窓を `stride` ずつずらしながら切り出す方法 |
| DataLoader | | Datasetから `batch_size` 個ずつ取り出して `[B, T]` にまとめる部品。`shuffle=True` で順番をランダムにする |
| `B`、`T`、`D` | | テンソルのshape。B はバッチサイズ、T は系列のトークン数、D は `d_model` |
