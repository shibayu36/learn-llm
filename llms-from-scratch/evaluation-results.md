# モデルの評価結果

学習を1回走らせるごとに、条件・結果・生成をここに1節ずつ足す。`runs/` はcommitしないので、残したい数値と生成結果はここに書く。進捗と決定は `progress.md`、条件の基準値は `plan.md`。

各節に書くこと。

- 目的と、基準から変えた条件
- パラメータ数・学習時間・最終loss・パープレキシティ
- lossの推移（学習ログの表）
- 「日本の首都は」の続き100文字を T=0・0.8・1 で1回ずつ。生成コマンドは `uv run main.py generate "日本の首都は" --run-name <run名> --max-new-tokens 100 --temperature <T>`
- 観察

学習中のgreedy生成の変化

- step 400〜1200: `1000000…`、`- - P - -` のような記号・数字の繰り返しに落ちる時期がある
- step 2400以降: 「その中で」「ことができる」「このため」のような3〜5文字の言い回しが安定して出て、「0」の繰り返しは消えた
- step 2800〜4200: 「自動車」「人気」「中心」「中国」「日本の中心」など内容語が混ざる

観察

- 学習率の効果と step の効果はこの1回で分けて読める。同じ2,000step時点で validation は 4.264 → 3.931（学習率）、そこから5,000stepで 3.649（step）
- 5,000stepでも下がり続けているが、最後の200stepの下げ幅は0.012で鈍ってきた。train と validation の差は全区間で約0.08で一定。trainを約3.5周しても過剰適合の気配はない
- T=0 は助詞と定型句で文の形は保つが、「その中では」を繰り返し、内容語がほぼ出ない
- T=0.8 は「医院」「指導」「技術」「実践」「購入」「韓国」「皮膚」と内容語が増える一方、「まずって」「おい方法べき」のように単語の途中で崩れる
- T=1 は「映画」「投稿」「消費」「建物」と語彙はさらに広がるが、「大撃先」「勃の鍵」のように語として成り立たない並びと、英字の断片が増える
- どの温度でも「東京」は出ない。「日本の首都」という6文字前の話題を参照して次の字を選ぶ力はなく、直前の数文字から次の1文字を決めている。層やヘッドを増やしてこれが変わるかがStage 4・5の見どころ
- この条件を以降の基準にした
