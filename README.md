# learn-llm

日本語のTiny GPTを実装しながら、LLMの内部を学ぶハンズオン。Part 1では固定した1万文書で学習し、意味のつながらない出力が文らしいつながりへ変わる様子を観察する。

- Part 1本文：`docs/part1.md`
- Part 1の操作デモ：`docs/demos/part1.html`
- 全体の計画：`docs/handson-plan.md`
- 資料作成・実践の進捗：`docs/handson-progress.md`
- 参照用の完成コード：`sample/`

本文はMarkdownで作成する。動く視覚表現は、必要な箇所だけ別HTMLの参考資料として用意する。読者は参照コードを見ながら、自分の作業場所で実装する。
